
# ☕ Cozy Cup Cafe

Welcome to **Cozy Cup Cafe**, a simple and interactive cafe website developed using HTML, CSS, and JavaScript. This project provides visitors with information about the cafe, displays its menu, and allows customers to select items and calculate their order total.

The project was created as a web development assignment to practice HTML structure, CSS styling, and JavaScript functionality.

## ✨ Features

- **Light/Dark Mode:** Switch between light and dark themes.
- **About Section:** Read information about the cafe using the Read More button.
- **Interactive Menu:** View available drinks and pastries.
- **Menu Filtering:** Filter menu items by category (All, Drinks, and Pastries).
- **Table Row Highlighting:** Highlight menu rows when hovering over them.
- **Order Calculator:** Select food and drinks to calculate the total price automatically.
- **Feedback Form:** Enter your username and email to submit feedback.
- **Age Discount Checker:** Check discount eligibility using the birth year.
- **Character Counter:** Track the remaining characters in special order instructions.
- **Opening Status:** Display the cafe's opening status.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/alishba12-cs/WebAssignment.git
   ```
2. Open the project folder:

   ```bash
   cd WebAssignment
   ```
3. Open `index.html` in your web browser.
4. Explore the cafe website and try its interactive features.

You can also open the project directly in Visual Studio Code and run it using the Live Server extension.
